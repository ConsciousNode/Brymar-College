What is Brymar College?

Brymar College v3.3.4 is a local LoRA and full-weight fine-tuning studio for RWKV-v7 models, built by ConsciousNode SoftWorks. It runs entirely on your machine — no cloud, no telemetry, no network required after model download. Named for Deltron 3030's Upgrade. Because it trains in multimodality, supporting 44 distinct formats including video, audio, and images.

Training Modes

LoRA Fine-tune only small adapter matrices (A/B) while keeping the base model frozen. Fast, memory-efficient, small checkpoints. Recommended for soul-corpus distillation.
Full Weight Train ALL model parameters end-to-end (embeddings, LayerNorms, all layers, head). Slower, larger checkpoints, but maximum expressiveness. Use for deep fine-tuning.

Configuration Fields

Base Model The RWKV-v7 World model to fine-tune. Default: RWKV-v7-World-1.5B. First run downloads from HuggingFace (~3GB). Subsequent runs use the cached copy.
Training Mode Choose LoRA for adapter-only training or Full Weight for end-to-end training of all parameters.
LoRA Rank Adapter rank r (LoRA mode only). Lower = fewer parameters, faster, less expressive. r=4 is the recommended start. Increase to 8 or 16 if loss plateaus early.
Training Steps Total optimizer steps. One step = grad_accum_steps sequences processed. 2000 steps is a reasonable baseline run. Watch loss — stop early if it flattens.
LR Schedule Learning rate schedule: Cosine (warmup + decay), Manual (constant), Step (multiply by 0.5 every N steps), or Exponential (smooth decay).
Corpus Directory Folder containing your training data. Supports multiple modalities:
Text: .txt, .md, .rst, .csv, .tsv, .json, .jsonl, .xml, .html, .yaml, .yml, .toml, .log, .tex, .org, .adoc
Image: .png, .jpg, .jpeg, .webp, .tiff, .gif, .avif, .svg, .bmp
Audio: .wav (native PCM parser)
Resume Checkpoint Optional. Path to a .json checkpoint from a previous run. Restores weights and resumes from the saved step count.

Supported Base Models

Brymar College strictly uses `.safetensors` or `.gguf` weights natively. If you provide a PyTorch `.pth` file, the system will seamlessly invoke a zero-dependency Python background worker to convert it to a `.safetensors` file on the fly before loading it into memory. Python 3 is required for this feature.

Compute Backend

By default, Brymar College runs in Auto mode, which attempts to offload matrix multiplication to an OpenCL-compatible GPU (like AMD GCN architecture). If your driver does not support `node-opencl`, you can explicitly set the Compute Backend to CPU Only to bypass hardware detection.

Supported Corpus Formats

.rofl Recurrent Omnimodal Friston Language model — Full FP32 precision. No quality loss. Largest file size.
.lmao Language Model, Active-inference, Omnimodal — Q4 symmetric quantization. 4-bit weights with per-group scaling. Good balance of quality and size.
.fuctrump Fristonian Underpinning Capabilities Transformer-agnostic Recurrent Unconcerned with Model Parameters — Q2 ternary quantization. {-1, 0, +1} weights. Maximum compression, some quality trade-off.
.json Legacy JSON format. Backward compatible with Phase 3 exports.

Hardware Requirements

Designed for constrained hardware. Tested target: Intel Core i7 Sandy Bridge, 12GB RAM + zRAM, AMD Radeon HD 7570. The 1.5B model runs comfortably in 12GB physical RAM. The 2.9B model requires zRAM headroom (~21GB effective). GPU is not required for Phases 1–4. Full-weight training uses more memory than LoRA mode.

Output

Checkpoints are saved to ./checkpoints/ every 200 steps as JSON files. In LoRA mode, only adapter weights are stored. In Full Weight mode, all model parameters are saved. Use Export Model to package a checkpoint in .rofl, .lmao, or .fuctrump format.

CLI Usage

The GUI is additive. The CLI remains fully functional:

node index.js train --corpus ./corpus --steps 2000 --rank 4
node index.js train --mode full --steps 1000
node index.js export --checkpoint ./checkpoints/checkpoint-002000.json --format rofl
node index.js export --checkpoint ./checkpoints/checkpoint-002000.json --format lmao
node index.js export --checkpoint ./checkpoints/checkpoint-002000.json --format fuctrump
